FoA Trainer — внутриигровой BepInEx-трейнер для Tainted Grail: The Fall of Avalon. Он позволяет изменять параметры игрового процесса, персонажа и инвентаря, использовать режим полёта, сохранять профили и выдавать предметы через расширенный Item Spawner с поиском. Интерфейс доступен на английском и русском языках.

## Установка

### Требования

- Windows
- Mono-версия/ветка Tainted Grail: The Fall of Avalon
- BepInEx 5

### Порядок установки

1. Установите [BepInEx 5](https://github.com/BepInEx/BepInEx/releases) для Mono-версии игры.
2. Один раз запустите игру, чтобы BepInEx создал необходимые папки.
3. Скачайте `FoATrainer_V17_1.dll` из [последнего релиза GitHub](https://github.com/Fenrisu1ven/FoA_Trainer/releases/latest).
4. Скопируйте DLL в папку:

   ```text
   <Папка игры>/BepInEx/plugins/
   ```

5. Удалите из папки plugins предыдущие версии DLL FoATrainer.
6. Запустите игру.
7. Нажмите `Insert`, чтобы открыть или скрыть трейнер.

`F8` — запасная клавиша открытия меню. `F11` переключает полноэкранный и оконный режимы трейнера.

## Управление

| Клавиша | Действие |
| --- | --- |
| `Insert` | Показать / скрыть трейнер |
| `F8` | Альтернативная клавиша открытия трейнера |
| `F11` | Полноэкранный / оконный режим |
| `F7` | Включить / выключить режим полёта |
| `WASD` | Перемещение в полёте |
| `Space` | Лететь вверх |
| `Ctrl` | Лететь вниз |
| `Shift` | Ускорение в полёте |

У отдельных функций есть собственные горячие клавиши — они указаны непосредственно в интерфейсе трейнера.

## Item Spawner

Item Spawner считывает доступные шаблоны предметов игры и распределяет их по многоуровневым фильтрам. Например:

```text
Оружие → Луки → Короткие / Средние / Тяжёлые
```

Также можно сразу выбрать конкретный тип оружия:

```text
Оружие → Мечи
```

Поиск выполняется внутри выбранной категории и подтипа. Сначала можно сузить базу с помощью фильтров, а затем искать только среди подходящих предметов.

Карточка выбранного предмета может содержать:

- Название
- Категорию и тип
- Выбранный уровень и количество
- Базовую цену и цену покупки
- Вес, если он доступен
- Рассчитанный урон оружия и другие характеристики, если они доступны
- Требования к характеристикам персонажа
- Сравнение с текущим персонажем и зелёную/красную индикацию требований

Наличие отдельных полей зависит от данных и методов расчёта, доступных для предмета в текущей версии игры.

## Профили

Профили сохраняются в папке:

```text
BepInEx/config/FoATrainer_Profiles/
```

В профиль входят переключатели, множители, значения редакторов, параметры полёта и язык интерфейса. Сохранение под уже существующим именем обновляет профиль. При следующем запуске последний сохранённый профиль автоматически выбирается и применяется после инициализации персонажа.

## Сборка из исходников

Клонируйте репозиторий и запустите входящий в комплект скрипт сборки:

```bash
git clone https://github.com/Fenrisu1ven/FoA_Trainer.git
cd FoA_Trainer
python tools/build.py
```

Готовый плагин будет создан по адресу:

```text
dist/FoATrainer_V17_1.dll
```

В проекте намеренно используется архитектура bootstrap + компиляция во время запуска, а не обычный проект для современного .NET SDK. Bootstrap BepInEx загружает runtime трейнера и компилирует его с использованием Mono-компилятора из игрового окружения и Mono-сборок игры.

Репозиторий не содержит игровых сборок, DLL BepInEx и других защищённых файлов игры.
